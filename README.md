## Password Strength Checker

A simple "Password Strength Checker" built with python and developed using visual studio code (VS Code).

This program checks a user's password and determines whether it is **Weak, Medium or Strong** based on different password requirements.

## Features
The program checks whether the password:
* Contains at least 8 characters
* Contains uppercase letters
* Contains numbers
* Contains special characters/symbols

It then calculates a score and displays the password strength.

## Technologies Used
* Python
* Visual studio code (VS Code)
  
## How It Works
The user enters a password when prompted.
The program checks the password against four requirements:
1. Password length
2. Uppercase letter
3. Number
4. Special character

The requirements met are added to a score:

* **0–1 points:**   WEAK
* **2–3 points:**  MEDIUM
* **4 points:**    STRONG

Example:
Enter your password: Holly@146

Password strength: STRONG
